# Wireshark Network Security Analysis

## Overview

This project analyzes basic network security mechanisms and network traffic using **Wireshark** in a virtualized/lab environment.

## Topics Covered

- Network security and the CIA triad
- Firewall configuration
- WPA2/WPA3 network encryption
- Changing default credentials
- System and software updates
- Wireshark network monitoring
- HTTP traffic analysis
- DNS traffic analysis
- TCP/HTTPS traffic observations
- Security risks of unencrypted HTTP and DNS
- Network security best practices

## Tools

- Wireshark
- Linux terminal
- Windows Defender Firewall
- Google Public DNS (`8.8.8.8`) for DNS-resolution verification

## Key Observations

The submitted report documents packet-level analysis of HTTP and DNS traffic. It explains that HTTP is unencrypted and can expose transmitted information to packet sniffing, while DNS traffic can be intercepted or spoofed. The report recommends secure protocols such as HTTPS, DNS over HTTPS (DoH), and DNS over TLS (DoT).
